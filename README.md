## What is Filtro?

Filtro brings a pop-art treatment to everyday photographs directly in the browser. Load an image and turn it into a striking composition influenced by Andy Warhol's use of repeated portraits, intense contrast, and unexpected color combinations.

The application is intended for artists, casual creators, and anyone who wants to try expressive photo effects without learning a complex editing program. Browser access, rapid processing, and automatically generated palettes support quick visual experimentation.

## Frequently Asked Questions

### Where does Filtro run?

Filtro is intended for browser use. You can open the hosted build or start a local copy from the repository.

### Which image files are supported?

Import formats that your browser supports and that the application's import control accepts. Larger images can require additional available browser memory.

### Is it possible to adjust the colors?

Color palettes are generated during Filtro's visual-processing workflow. The controls in the current build let you explore the color choices that it provides.

### How can I find newer versions?

Review the repository for project updates and newer builds. The hosted download link leads to the currently published location.

### What should I do if Filtro will not load?

First make sure the hosted page or local server can be reached, then refresh it in a current browser. If you are running locally, confirm that the required project development or build steps were completed.

### Where can I submit an issue?

Create an issue in the project repository. Include your browser, operating environment, image format, and the steps that led to the problem.
